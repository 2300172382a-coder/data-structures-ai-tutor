AI 实际输出：

```text
为了使用邻接表实现广度优先搜索（BFS），我们需要确保每个顶点只被访问一次且仅加入队列一次，以防止重复入队。

首先分析时间复杂度：
- 邻接表 BFS 的时间复杂度为 `O(|V|+|E|)`。
- 额外空间复杂度为 `O(|V|)`（用于存储访问标记和队列）。

接下来明确 visited 应在邻接点入队时还是出队时设置：

1. **应在入队时标记访问**：
   - 当顶点 `u` 入队时，将其对应的访问标志 `visited[u]` 设置为 `true`。
   - 这样可以确保每个顶点只被访问一次，并且不会重复加入队列。

2. **避免重复入队的方法**：
   - 在出队后将顶点 `u` 的访问标志设置为 `true`，但此时顶点已经从队列中移除。
   - 如果在出队时再标记访问，则可能会导致同一顶点被多次加入队列。例如，在某个前驱节点的邻接点入队操作中，该顶点可能已经被其他前驱节点的邻接点重复加入队列。

综上所述：
- 应在入队时设置 `visited[u] = true`。
- 这样可以确保每个顶点只被访问一次，并且不会重复加入队列。

以下是实现代码示例：

~~~cpp
vector<int> bfs(const vector<vector<int>>& graph, int start) {
    if (start < 0 || start >= static_cast<int>(graph.size())) return {};

    vector<bool> visited(graph.size(), false);
    queue<int> pending;
    vector<int> order;

    // 入队时标记访问
    visited[start] = true;
    pending.push(start);

    while (!pending.empty()) {
        int u = pending.front(); pending.pop();
        order.push_back(u);

        for (int v : graph[u]) {
            if (!visited[v]) {
                visited[v] = true;  // 入队时标记
                pending.push(v);
            }
        }
    }

    return order;
}
~~~

通过这种方式，我们确保每个顶点只被访问一次，并且不会重复加入队列。
```

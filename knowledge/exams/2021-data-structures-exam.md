## 一、单项选择题（第1~11题，每题2分）

### 1.
已知头指针 h 指向一个带头结点的非空循环链表，结点结构为：

| data | next |
|------|------|

其中 next 是指向直接后继结点的指针，p 是尾指针，q 是临时指针。现在要删除该链表的第一个元素，正确的语句序列是______。

- A. h->next = h->next->next; q = h->next; free(q);
- B. q = h->next; h->next = h->next->next; free(q);
- C. q = h->next; h->next = q->next; if(p != q) p = h; free(q);
- D. q = h->next; h->next = q->next; if(p == q) p = h; free(q);
> ✅ **答案**：D
> 📖 **解析**：带表头结点的循环链表将首结点移到表尾（或类似操作），按指针同步修改，正确的语句序列为D。


### 2.
已知初始为空的队列 Q 的一端仅能进行入队操作，另外一端既能进行入队操作又能进行出队操作。若 Q 的入队序列是 1, 2, 3, 4, 5，则不能得到的出队序列是______。

- A. 5, 4, 3, 1, 2
- B. 5, 3, 1, 2, 4
- C. 4, 2, 1, 3, 5
- D. 4, 1, 3, 2, 5
> ✅ **答案**：D
> 📖 **解析**：一端仅入队、另一端可入可出，模拟各选项的出队序列，D无法得到。


### 3.
已知二维数组 A 按行优先方式存储，每个元素占用 1 个存储单元。若元素 A[0][0] 的存储地址是 100，A[3][3] 的存储地址是 220，则元素 A[5][5] 的存储地址是______。

- A. 295
- B. 300
- C. 301
- D. 306
> ✅ **答案**：B
> 📖 **解析**：行优先存储：addr(A[3][3])=addr(A[0][0])+3×每行元素数+3，按题给数组规模计算得300。


### 4.
某森林 F 对应的二叉树为 T，若 T 的先序遍历序列是 a, b, d, c, e, g, f，中序遍历序列是 b, d, a, e, g, c, f，则 F 中树的棵数是______。

- A. 1
- B. 2
- C. 3
- D. 4
> ✅ **答案**：C
> 📖 **解析**：由二叉树T的先序a,b,d,c,e,g,f与中序b,d,a,e,g,c,f重建树形，再转回森林F，F中结点d?的双亲/兄弟关系对应选项C。


### 5.
若某二叉树有 5 个叶结点，其权值分别为 10, 12, 16, 21, 30，则其最小的带权路径长度（WPL）是______。

- A. 89
- B. 200
- C. 208
- D. 289
> ✅ **答案**：B
> 📖 **解析**：构造哈夫曼树：10+12=22、16+21=37、22+30=52、37+52=89，WPL=22+37+89?根的两次合并值之和=89+52+22?WPL=(10+12)+(16+21)+89??最小带权路径长度为200?以官方答案B（200）为准：WPL=Σ权×路长=10×3+12×3+16×2+21×2+30×2=200。


### 6.

- A. 16
- B. 20

- D. 25

### 8.

### 9.
在一棵高度为 3 的 3 阶 B 树中，根为第 1 层，若第 2 层中有 4 个关键字，则该树的结点个数最多是______。

- A. 11
- B. 10
- C. 9
- D. 8
> ✅ **答案**：A
> 📖 **解析**：3阶B树第2层最多2个结点各含2关键字与题设4关键字一致；第2层结点各取3个孩子，第3层最多6个结点，总计1+2+6?最大结点数=1+2+8=11（每结点关键字取上限2时孩子为3，重新推演按官方答案A=11）。


### 10.
设数组 S[] = {93, 946, 372, 9, 146, 151, 301, 485, 236, 327, 43, 892}，采用最低位优先（LSD）基数排序将 S 排列成升序序列。第 1 趟分配、收集后，元素 372 之前、之后紧密相邻的元素分别是______。

### 11.

- A. 9, 8, 7, 6, 5, 4, 1

## 二、综合应用题（第41~42题）

### 41.（15分）
已知无向连通图 G 由顶点集 V 和边集 E 组成，|E|>0，当 G 中度为奇数的顶点个数为不大于 2 的偶数时，G 存在包含所有边且长度为 |E| 的路径（称为 EL 路径）。设图 G 采用邻接矩阵存储，类型定义如下：

```c
typedef struct {                    // 图的定义
    int numVertices, numEdges;      // 图中实际的顶点数和边数
    char VerticesList[MAXV];        // 顶点表。MAXV 为已定义常量
    int Edge[MAXV][MAXV];           // 邻接矩阵
} MGraph;
```

请设计算法 int IsExistEL(MGraph G)，判断 G 是否存在 EL 路径，若存在，则返回 1，否则返回 0。要求：

1）给出算法的基本设计思想；
2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释；
3）说明你所设计算法的时间复杂度和空间复杂度。
> ✅ **参考答案**：见要点解析
> 📖 **参考解析**：参考答案要点：EL路径（欧拉路径）存在当且仅当图连通且奇度顶点数为0或2。邻接矩阵存储下依次累加各行非零元素个数求各顶点度，统计奇度顶点数count，count为0或2返回1，否则返回0。需遍历全矩阵，时间O(n²)，空间O(1)。


### 42.（8分）
已知某排序算法如下：

```c
void cmpCountSort(int a[], int b[], int n)
{
    int i, j, *count;
    count = (int *)malloc(sizeof(int)*n);   // C++语言：count = new int[n];
    for (i = 0; i < n; i++)
        count[i] = 0;
    for (i = 0; i < n-1; i++)
        for (j = i+1; j < n; j++)
            if (a[i] < a[j])
                count[j]++;
            else
                count[i]++;
    for (i = 0; i < n; i++)
        b[count[i]] = a[i];
    free(count);                  // C++语言：delete count;
}
```

请回答下列问题：

1）若有 int a[] = {25, -10, 25, 10, 11, 19}, b[6];，则调用 cmpCountSort(a, b, 6) 后数组 b 中的内容是什么？
2）若 a 中含有 n 个元素，则算法执行过程中，元素之间的比较次数是多少？
3）该算法是稳定的吗？若是，则阐述理由；否则，修改为稳定排序算法。

---
> ✅ **参考答案**：见要点解析
> 📖 **参考解析**：参考答案要点：cmpCountSort基于计数思想：对每个元素统计比它小的元素个数count，据此把元素直接放到b的正确位置（如count[1]=3表示有3个元素比a[1]大）。比较次数为n(n-1)/2；排序结果b={-1,0,10,11,19,25}。第3问结论：不是稳定排序——相等元素比较时若让前面元素count也加1，会使原序列靠前的相等元素排到靠后位置，次序颠倒。

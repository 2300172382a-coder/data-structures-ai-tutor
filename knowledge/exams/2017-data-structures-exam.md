## 一、单项选择题（第1~11题，每题2分）

### 1.
下列函数的时间复杂度是______。

```c
int func(int n) {
    int i = 0, sum = 0;
    while (sum < n)
        sum += ++i;
    return i;
}
```

- A. O(log₂n)
- B. O(n^(1/2))
- C. O(n)
- D. O(nlog₂n)
> ✅ **答案**：B
> 📖 **解析**：sum累加1,2,3,...至超过n需约√(2n)次，时间复杂度O(n^(1/2))。


### 2.
下列关于栈的叙述中，错误的是______。

Ⅰ. 采用非递归方式重写递归程序时必须使用栈
Ⅱ. 函数调用时，系统要用栈保存必要的信息
Ⅲ. 只要确定了入栈次序，即可确定出栈次序
Ⅳ. 栈是一种受限的线性表，允许在其两端进行操作

- A. 仅Ⅰ
- B. 仅Ⅰ、Ⅱ、Ⅲ
- C. 仅Ⅰ、Ⅲ、Ⅳ
- D. 仅Ⅱ、Ⅲ、Ⅳ
> ✅ **答案**：C
> 📖 **解析**：递归转非递归“必须”用栈表述过于绝对（Ⅰ错）；Ⅱ函数调用用栈正确；Ⅲ、Ⅳ亦有错误表述，故错误的是Ⅰ、Ⅲ、Ⅳ。


### 3.
适用于压缩存储稀疏矩阵的两种存储结构是______。

- A. 三元组表和十字链表
- B. 三元组表和邻接矩阵
- C. 十字链表和二叉链表
- D. 邻接矩阵和十字链表
> ✅ **答案**：A
> 📖 **解析**：稀疏矩阵压缩存储常用三元组表（顺序）和十字链表（链式）。


### 4.
要使一棵非空二叉树的先序序列与中序序列相同，其所有非叶结点须满足的条件是______。

- A. 只有左子树
- B. 只有右子树
- C. 结点的度均为 1
- D. 结点的度均为 2
> ✅ **答案**：B
> 📖 **解析**：先序=中序要求每个结点无左子树，即所有非叶结点只有右子树。


### 5.
已知一棵二叉树的树形如下图所示，其后序序列为 e, a, c, b, d, g, f，树中与结点 a 同层的结点是______。

> 图形题：二叉树——根结点为 f；f 的左孩子为 c、右孩子为 g；c 只有左孩子 a，a 只有左孩子 e；g 只有左孩子 d，d 只有左孩子 b。原图见 `images/2017/page-1.png` 第5题处。

- A. c
- B. d
- C. f
- D. g
> ✅ **答案**：B
> 📖 **解析**：由后序e,a,c,b,d,g,f与给定树形反推各结点位置，与a同层的结点是d。


### 6.
已知字符集 {a, b, c, d, e, f, g, h}，若各字符的哈夫曼编码依次是 0100, 10, 0000, 0101, 001, 011, 11, 0001，则编码序列 0100011001001011110101 的译码结果是______。

- A. acgabfh
- B. adbagbb
- C. afbeagd
- D. afeefgd
> ✅ **答案**：D
> 📖 **解析**：按哈夫曼编码逐前缀切分选项串，D中afeefgd出现无法匹配的编码（或长度不符），不可能是编码结果。


### 7.
已知无向图 G 含有 16 条边，其中度为 4 的顶点个数为 3，度为 3 的顶点个数为 4，其他顶点的度均小于 3。图 G 所含的顶点个数至少是______。

- A. 10
- B. 11
- C. 13
- D. 15
> ✅ **答案**：B
> 📖 **解析**：顶点度之和=2×16=32；度4顶点3个+度3顶点4个占24度，其余顶点度≤2，顶点数最少时其余度取2：8/2=4个，共3+4+4=11个。


### 8.
下列二叉树中，可能成为折半查找判定树（不含外部结点）的是______。

> 图形题：A、B、C、D 为四棵结点数相同、树形互不相同的二叉树（结点以空心圆表示，未标注关键字）。原图见 `images/2017/page-2.png` 第8题处。

- A. / B. / C. / D.（四棵二叉树图形）
> ✅ **答案**：A
> 📖 **解析**：图形题：按折半查找判定树“中间结点为根、左右子树结点数相差不超过1且按中序有序”的性质检验四棵树，A可能，见 images/2017/page-2.png。


### 9.
下列应用中，适合使用 B+ 树的是______。

- A. 编译器中的词法分析
- B. 关系型数据库系统中的索引
- C. 网络中的路由表快速查找
- D. 操作系统的磁盘空闲空间管理
> ✅ **答案**：B

### 10.
在内部排序时，若选择了归并排序而没有选择插入排序，则可能的理由是______。

Ⅰ. 归并排序的程序代码更短
Ⅱ. 归并排序的占用空间更少
Ⅲ. 归并排序的运行效率更高

- A. 仅Ⅱ
- B. 仅Ⅲ
- C. 仅Ⅰ、Ⅱ
- D. 仅Ⅰ、Ⅲ
> ✅ **答案**：B
> 📖 **解析**：归并排序代码更长（Ⅰ错）、需要O(n)辅助空间（Ⅱ错）；Ⅲ（归并稳定且效率稳定）成立，仅Ⅲ是合理理由。


### 11.
下列排序方法中，若将顺序存储更换为链式存储，则算法的时间效率会降低的是______。

Ⅰ. 插入排序
Ⅱ. 选择排序
Ⅲ. 起泡排序
Ⅳ. 希尔排序
Ⅴ. 堆排序

- A. 仅Ⅰ、Ⅱ
- B. 仅Ⅱ、Ⅲ
- C. 仅Ⅲ、Ⅳ
- D. 仅Ⅳ、Ⅴ

---
> ✅ **答案**：D
> 📖 **解析**：插入、希尔等依赖顺序存储随机访问；更换为链式存储后时间效率明显降低的是折半插入排序（Ⅳ）与堆排序（Ⅴ），选D。

### 41.（15分）
请设计一个算法，将给定的表达式树（二叉树）转换为等价的中缀表达式（通过括号反映操作符的计算次序）并输出。例如，当下列两棵表达式树作为算法的输入时，输出的等价中缀表达式分别为 (a+b)*(c*(-d)) 和 (a*b)+(-(c-d))。

> 图形题（两棵表达式树）：
> 树一：根为 *；左子树根为 +（其左、右孩子分别为操作数 a、b）；右子树根为 *（其左孩子为操作数 c，右孩子为单目运算符 −，该 − 仅有右孩子 d），对应输出 (a+b)*(c*(-d))。
> 树二：根为 +；左子树根为 *（其左、右孩子分别为操作数 a、b）；右子树为单目运算符 −（仅有左孩子，其左子树根为 −，该 − 的左、右孩子分别为 c、d），对应输出 (a*b)+(-(c-d))。
> 原图见 `images/2017/page-5.png` 第41题处。

二叉树结点定义如下：

```c
typedef struct node {
    char data[10];      // 存储操作数或操作符
    struct node *left, *right;
} BTree;
```

要求：

1. 给出算法的基本设计思想；
2. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
> ✅ **参考答案**：见要点解析
> 📖 **参考解析**：参考答案要点：基于中序遍历转换：叶结点（操作数）直接输出；深度>1的分支结点在其子树表达式两侧加括号——遍历左子树前输出'('，遍历完右子树后输出')'；根结点（深度1）不加括号。递归函数BtreeToExp(root,deep)实现，时间O(n)。


### 42.（8分）
使用 Prim（普里姆）算法求带权连通图的最小（代价）生成树（MST）。请回答下列问题。

1. 对下列图 G，从顶点 A 开始求 G 的 MST，依次给出按算法选出的边；
2. 图 G 的 MST 是唯一的吗？
3. 对任意的带权连通图，满足什么条件时，其 MST 是唯一的？

> ✅ **参考答案**：见要点解析
> 📖 **参考解析**：参考答案要点：(1)Prim是贪心策略：从顶点A开始，每次选择连接树集合S与S外顶点的权值最小边加入，依次为(A,D)、(D,E)、(C,E)、(B,C)；(2)图G的MST唯一（包含了图中权值最小的四条边）；MST唯一的充分条件示例：带权连通图中任意环上的边权值互不相同时MST唯一。

## 一、单项选择题（第1~10题，每题2分）

### 1.
已知两个长度分别为 m 和 n 的升序链表，若将它们合并为一个长度为 m+n 的降序链表，则最坏情况下的时间复杂度是______。

- A. O(n)
- B. O(mn)
- C. O(min(m,n))
- D. O(max(m,n))
> ✅ **答案**：D
> 📖 **解析**：两升序链表合并为降序链表可采用逐个取元素头插，比较次数最坏为m+n-1次，但链表不需移动元素、时间由较长链表决定，为O(max(m,n))。


### 2.
一个栈的入栈序列为 1, 2, 3, …, n，其出栈序列是 p₁, p₂, p₃, …, pₙ。若 p₂ = 3，则 p₃ 可能取值的个数是______。

- A. n-3
- B. n-2
- C. n-1
- D. 无法确定
> ✅ **答案**：C
> 📖 **解析**：入栈序列1..n且p2=3：p3可取除3外的n-1个值（1、2及其他均可通过合适栈操作实现）。


### 3.
若将关键字 1, 2, 3, 4, 5, 6, 7 依次插入到初始为空的平衡二叉树 T 中，则 T 中平衡因子为 0 的分支结点的个数是______。

- A. 0
- B. 1
- C. 2
- D. 3
> ✅ **答案**：D
> 📖 **解析**：依次插入1..7构建AVL，模拟旋转过程，平衡因子为0的分支结点共3个。


### 4.
已知三叉树 T 中 6 个叶结点的权分别是 2, 3, 4, 5, 6, 7，T 的带权（外部）路径长度最小是______。

- A. 27
- B. 46
- C. 54
- D. 56
> ✅ **答案**：B
> 📖 **解析**：6个叶结点的三叉哈夫曼树需补1个虚叶（(6-1) mod (3-1)=1），构造后最小带权路径长度WPL=46。


### 5.
若 X 是后序线索二叉树中的叶结点，且 X 存在左兄弟结点 Y，则 X 的右线索指向的是______。

- A. X 的父结点
- B. 以 Y 为根的子树的最左下结点
- C. X 的左兄弟结点 Y
- D. 以 Y 为根的子树的最右下结点
> ✅ **答案**：A
> 📖 **解析**：X是叶且有左兄弟Y，说明X是其父结点的最后一个孩子，后序线索树中X的右线索（后继）指向其父结点。


### 6.
在任意一棵非空二叉排序树 T₁ 中，删除结点 v 之后形成二叉排序树 T₂，再将 v 插入 T₂ 形成二叉排序树 T₃。下列关于 T₁ 与 T₃ 的叙述中，正确的是______。

Ⅰ. 若 v 是 T₁ 的叶结点，则 T₁ 与 T₃ 不同
Ⅱ. 若 v 是 T₁ 的叶结点，则 T₁ 与 T₃ 相同
Ⅲ. 若 v 不是 T₁ 的叶结点，则 T₁ 与 T₃ 不同
Ⅳ. 若 v 不是 T₁ 的叶结点，则 T₁ 与 T₃ 相同

- A. 仅 Ⅰ、Ⅲ
- B. 仅 Ⅱ、Ⅳ
- C. 仅 Ⅱ、Ⅲ
- D. 仅 Ⅰ、Ⅳ
> ✅ **答案**：C
> 📖 **解析**：BST删除再插入同一关键字：Ⅱ、Ⅲ正确（树形可能恢复、中序序列不变），Ⅰ、Ⅳ不成立，故仅Ⅱ、Ⅲ。


### 7.
设图的邻接矩阵 A 如下所示。各顶点的度依次是______。

```
        | 0 1 0 1 |
    A = | 0 0 1 1 |
        | 0 1 0 0 |
        | 1 0 0 0 |
```

- A. 1, 2, 1, 2
- B. 2, 2, 1, 1
- C. 3, 4, 2, 3
- D. 4, 4, 2, 2
> ✅ **答案**：C
> 📖 **解析**：无向图各顶点度=邻接矩阵对应行列非零元素合计，计算得3,4,2,3。


### 8.
若对如下无向图进行遍历，则下列选项中，不是广度优先遍历序列的是______。

- A. h, c, a, b, d, e, g, f
- B. e, a, f, g, b, h, c, d
- C. d, b, c, a, h, e, f, g
- D. a, b, c, d, h, e, f, g

> 图形题：顶点 a、b、c、d、e、f、g、h；无向边：a-b、a-e、a-h、b-c、b-d、c-d、c-h、e-f、e-g。布局：a 在顶部，b、e 在第二层，c、d、f、g 在第三层，h 在底部。原图见 `images/2013/page-2.png` 第8题处（题干末行在第1页末，选项与图在第2页开头）。
> ✅ **答案**：D
> 📖 **解析**：由图的邻接关系逐项模拟BFS（借助队列逐层访问），选项D的序列违背邻接关系，不可能。


### 9.
下列 AOE 网表示一项包含 8 个活动的工程。通过同时加快若干活动的进度可以缩短整个工程的工期。下列选项中，加快其进度就能缩短工程工期的是______。

- A. c 和 e
- B. d 和 e
- C. f 和 d
- D. f 和 h

> 图形题：事件（顶点）1、2、3、4、5、6；活动（有向边）及工期：a: 1→2(3)、b: 1→3(8)、c: 2→4(9)、d: 3→2(4)、e: 2→5(6)、f: 3→5(10)、g: 4→6(6)、h: 5→6(9)。原图见 `images/2013/page-2.png` 第9题处。
> ✅ **答案**：C
> 📖 **解析**：按事件最早/最迟时间计算各活动时间余量，f和d的余量为0（或按题设条件判定），为关键活动，选C（f和d）。


### 10.
在一棵高度为 2 的 5 阶 B 树中，所含关键字的个数最少是______。

- A. 5
- B. 7
- C. 8
- D. 14

---
> ✅ **答案**：A
> 📖 **解析**：高度2的5阶B树：根1个关键字、2个孩子各至少⌈5/2⌉-1=2个关键字，最少1+2+2=5个。


## 二、综合应用题（第41~42题）

### 41.（13分）
已知一个整数序列 A = (a₀, a₁, …, aₙ₋₁)，其中 0 ≤ aᵢ < n（0 ≤ i < n）。若存在 a_p1 = a_p2 = … = a_pm = x 且 m > n/2（0 ≤ p_k < n，1 ≤ k ≤ m），则称 x 为 A 的主元素。例如 A = (0, 5, 5, 3, 5, 7, 5, 5)，则 5 为主元素；又如 A = (0, 5, 5, 3, 5, 1, 5, 7)，则 A 中没有主元素。假设 A 中的 n 个元素保存在一个一维数组中，请设计一个尽可能高效的算法，找出 A 的主元素。若存在主元素，则输出该元素，否则输出 -1。要求：

(1) 给出算法的基本设计思想。
(2) 根据设计思想，采用 C、C++ 或 Java 语言描述算法，关键之处给出注释。
(3) 说明你所设计算法的时间复杂度和空间复杂度。
> ✅ **参考答案**：见要点解析
> 📖 **参考解析**：参考答案要点：求主元素（出现次数超过n/2）用两步法：①扫描数组选候选值，相同计数加1、不同减1，减到0重新选候选；②再扫描一遍统计候选值实际出现次数，超过n/2则为主元素，否则不存在返回-1。时间O(n)、空间O(1)；排序法O(nlog₂n)最多得11分。


### 42.（10分）
设包含 4 个数据元素的集合 S = {"do", "for", "repeat", "while"}，各元素的查找概率依次为 p₁ = 0.35, p₂ = 0.15, p₃ = 0.15, p₄ = 0.35。将 S 保存到一个长度为 4 的顺序表中，采用折半查找法，查找成功时的平均查找长度为 2.2。请回答：

(1) 若采用顺序存储结构保存 S，且求平均查找长度更短，则元素应如何排列？应使用何种查找法？查找成功时的平均查找长度是多少？
(2) 若采用链式存储结构保存 S，且求平均查找长度更短，则元素应如何排列？应使用何种查找法？查找成功时的平均查找长度是多少？
> ✅ **参考答案**：见要点解析
> 📖 **参考解析**：参考答案要点：查找概率不等时折半查找未必最优。(1)采用顺序存储按查找概率降序存放，顺序查找ASL=0.35×1+0.35×2+0.15×3+0.15×4=2.1，优于折半查找的2.2；(2)链式存储按概率降序+顺序查找（ASL=2.1），或构造查找概率大的结点靠近根的二叉排序树（ASL=2.0），核心是把高概率元素放在靠近起始/根的位置。

# 数据结构实现中的常见错误

## 指针与边界

- 链表删除后继续访问已释放结点：释放前先保存必要后继，释放后不要解引用旧指针。
- 逆置链表时未保存 `next`：第一次改向后便失去剩余链表。
- 数组循环使用 `i <= n`：合法下标从 0 到 `n-1`，通常应写 `i < n`。
- 空树递归缺少终止条件：每个递归树函数首先处理空指针。

## 栈与队列

- 混用不同循环队列约定：在代码或答案开头写清 `front`、`rear` 分别指向什么。
- BFS 在出队时才标记访问：一个结点可能被多个前驱重复加入队列，应在入队时标记。
- 表达式求值忽略括号和结合性：优先级相同不代表所有运算都按同一方向结合。

## 树与图

- 把完全二叉树当满二叉树：完全只要求最后一层从左连续。
- 认为前序加后序总能唯一确定树：一般二叉树不成立。
- DFS/BFS 只从一个顶点启动：非连通图需要外层循环形成遍历森林。
- 对含负权边的图使用 Dijkstra：已确定距离可能被后续负边改小。

## 查找与排序

- 在链表上套用折半查找：定位中点不是 `O(1)`，失去优势。
- 开放定址散列表删除时直接清空槽：会截断其他元素的探测链。
- 快速排序划分循环在大量相等值时不前进：每个分支必须确保游标移动或采用三路划分。
- 声称某算法“最快”：应说明输入规模、分布、稳定性和空间约束。

## 调试清单

1. 先构造最小失败输入：空、1 个、2 个、重复值、已排序、逆序。
2. 每轮循环写出不变量，并检查变量是否持续向终止条件推进。
3. 使用地址检查器或内存工具发现越界、重复释放和泄漏。
4. 同时验证结果和原结构是否被意外破坏。
5. 用参考实现或暴力算法对小规模随机数据做差分测试。

## 三种排序算法对比

| 算法 | 时间复杂度 | 数组额外空间 | 稳定性 |
|---|---|---|---|
| 快速排序 | 平均 `O(n log n)`，最坏 `O(n^2)` | 平均递归栈 `O(log n)` | **不稳定** |
| 归并排序 | 最好、平均、最坏均为 `O(n log n)` | `O(n)` | **稳定** |
| 堆排序 | 最好、平均、最坏均为 `O(n log n)` | `O(1)` | **不稳定** |

特别注意：堆排序是不稳定排序；需要稳定性时不能因为它是原地算法就选择它。要求稳定且内存充足时可选归并排序；内存受限且不要求稳定时可选堆排序；平均性能优先时可选改进快速排序。

## BFS 的访问标记时机

发现一个尚未访问的邻接点 `v` 时，必须先设置 `visited[v] = true`，随后执行 `queue.push(v)`。也可表述为“在入队时标记”，不能等到 `v` 出队时才标记，否则多个前驱可能把同一顶点重复加入队列。

```cpp
if (!visited[v]) {
    visited[v] = true;  // 先标记
    pending.push(v);    // 后入队
}
```

邻接表 BFS 的时间复杂度为 `O(|V|+|E|)`，额外空间为 `O(|V|)`。

## 前序与后序的唯一性

前序遍历加后序遍历通常不能唯一确定一般二叉树，因为只有一个孩子的结点无法判断该孩子在左侧还是右侧。结点值互异时，前序加中序或后序加中序才可唯一重建。

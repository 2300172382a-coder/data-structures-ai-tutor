# 第二章 栈、队列与数组

## 栈

栈是只允许在同一端插入和删除的线性表，遵循后进先出（LIFO）。栈顶执行入栈和出栈，另一端称栈底。顺序栈用数组与栈顶下标实现；链栈通常以链表头部作为栈顶，使入栈、出栈均为 `O(1)`。

典型应用包括括号匹配、表达式求值、函数调用、深度优先搜索和撤销操作。表达式处理中，操作数栈保存数据，运算符栈根据优先级决定何时归约。括号使局部表达式优先完成。

## 队列

队列只允许在一端入队、另一端出队，遵循先进先出（FIFO）。典型应用包括任务调度、打印缓冲、广度优先搜索和生产者—消费者系统。

普通数组队列连续出队后会在数组前部留下空位，形成“假溢出”。循环队列通过模运算复用这些位置。若 `front` 指向队头元素、`rear` 指向下一可插入位置，常见判定是：

- 空队列：`front == rear`
- 保留一个空槽时的满队列：`(rear + 1) % capacity == front`
- 队列长度：`(rear - front + capacity) % capacity`

不同教材可能让 `rear` 指向队尾元素，公式会变化。答题时必须先写清指针语义，不能机械套公式。

## 特殊矩阵与数组

多维数组在内存中仍是一维连续序列。行优先存储下，二维数组 `A[m][n]` 中 `A[i][j]` 相对首地址的元素偏移为 `i*n+j`（下标从 0 开始）。列优先则为 `j*m+i`。

对称矩阵、三角矩阵和稀疏矩阵可压缩存储。三元组顺序表用 `(row, column, value)` 记录非零元素；十字链表同时按行、列连接非零结点，适合动态修改。

## 常见误区

- 栈的“后进先出”约束的是可观察的出栈次序，并不意味着所有元素必须先全部入栈。
- 循环队列的判空、判满公式取决于 `front`、`rear` 定义和是否保留空槽。
- 递归使用系统调用栈；递归深度过大可能栈溢出。
